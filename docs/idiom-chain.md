# 成语接龙

成语接龙是可选的大厅娱乐玩法，默认由 `idiom_chain.enabled` 控制。

## 命令

```text
#接龙 画蛇添足
#足智多谋
#同音接龙 画蛇添足
#提示
#解释
#解释 画蛇添足
#状态
#结束
```

- `#接龙 成语` 开始普通模式，后续成语的首字必须接上一个成语的尾字。
- `#同音接龙 成语` 开始同音模式，后续成语按无声调读音衔接。
- 开局后直接发送 `#成语` 提交下一条成语。
- `#提示` 推荐当前可以继续的成语，但不会自动提交。
- `#解释` 查看当前成语的来源和解释；带成语参数时查询指定成语。
- `#状态` 查看当前对局，`#结束` 结束当前对局。

## 规则

成语必须存在于内置词库，空格和常见标点会被忽略。简体和繁体按词库中的写法区分；同一局已经使用过的成语不能再次使用。默认不允许同一玩家连续提交，也只有开局玩家可以结束对局。

对局在长时间没有新输入时会自动结束；进入新大厅、关闭游戏或启动其他娱乐玩法也会结束当前对局。

## 配置

```yaml
idiom_chain:
  enabled: true
  history_limit: 200
  idle_timeout_seconds: 300
  allow_consecutive_player: false
  allow_anyone_stop: false
```

词库随发布包放在 `assets/idioms.txt`，通常不需要修改。调整超时或结束权限后重启程序即可生效。

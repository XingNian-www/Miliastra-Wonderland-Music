# 数字炸弹

大厅里轮流猜数字的娱乐玩法：系统在一个区间里藏一个「炸弹数字」，玩家依次猜，每猜一次区间就收窄一格，谁先猜到炸弹谁就输。

## 开局与加入

```text
#数字炸弹     创建房间（发起人）
#加入         加入房间
#开始         开始游戏（仅发起人，至少 2 人）
#状态         查看当前区间和轮到谁
#结束         结束整局
#重来         保留成员再来一局（仅发起人）
#50           轮到你时猜 50（必须带 #）
```

房间人数 **2 ~ 11 人**，超过 5 人时范围上限会变大（见下）。

## 玩法规则

- 系统在 **[下限, 上限]** 之间随机一个隐藏的炸弹数字，默认 **1 ~ 100**。
- 当前玩家在大厅发送 **`#数字`**（例如 `#50`）：
  - 猜中炸弹 → 爆炸，该玩家输，结算会公布炸弹数字；
  - 猜小了 → 新区间下界 = 猜的数字 + 1；
  - 猜大了 → 新区间上界 = 猜的数字 - 1；
  - 猜完轮到下一位。
- 区间只剩一个数字时，轮到谁谁必中。
- 越界、重复猜过的数字、或者发的是非数字：只提示当前玩家，**不消耗回合**。
- 轮到某人后超过 `turn_timeout_seconds`（默认 60 秒）没猜，程序会在剩余区间里**自动随机猜一个**，保证游戏继续。

## 上限随人数变大

默认上限 100。人数超过 5 后，每多 1 人上限加 20：

| 人数 | 区间 |
| --- | --- |
| 2 ~ 5 | 1 ~ 100 |
| 6 | 1 ~ 120 |
| 7 | 1 ~ 140 |
| 11 | 1 ~ 220 |

## 配置

Web 面板「配置中心」的 `number_bomb` 段：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | 开启 | 是否允许开局 |
| `min` | 1 | 区间固定下界 |
| `max` | 100 | 5 人以内时的上限 |
| `extra_range_per_player` | 20 | 超过 5 人后每多 1 人增加的上限 |
| `min_players` | 2 | 开局最少人数 |
| `max_players` | 11 | 房间最多人数 |
| `turn_timeout_seconds` | 60 | 回合超时秒数，超时自动随机猜 |

修改后需重启程序生效（与其它玩法配置一致）。

## 与其它玩法的关系

同一时间只能进行一个娱乐玩法（成语接龙 / 斗地主 / 跑得快 / 海龟汤 / 谁是卧底 / 数字炸弹）。数字炸弹进行中，大厅里的蓝字消息会被当作猜测处理；`#` 开头的命令仍然照常路由。

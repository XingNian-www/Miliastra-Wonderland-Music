# 个人歌单

个人歌单按游戏内昵称归属；好友备注名只用于识别和展示，不会把不同用户合并。歌单命令遵循游戏 OCR 的无空格语法。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| @收藏 | 收藏当前正在播放的歌曲 |
| @取消收藏、@歌单删除 | 取消收藏当前歌曲 |
| @歌单 | 打开当前用户的推荐窗口 |
| @1 到 @5 | 仅在当前推荐窗口内选择歌曲；窗口外不作为命令 |
| @换一批 | 在当前窗口重抽候选 |
| @关闭 | 关闭推荐窗口 |
| @歌单随机、@随机歌单 | 从已收藏歌曲中随机播放 |
| @歌单清空 | 请求清空歌单；需要再次确认 |
| @导入QQ歌单<ID> | 读取 QQ 音乐公开歌单并发送预览 |
| @导入网易歌单<ID> | 读取网易云公开歌单并发送预览 |
| @确认导入 | 将上次预览的歌单加入当前用户收藏 |
| @取消导入 | 放弃当前导入 |
| @歌单帮助 | 查看帮助 |

## 导入歌单

发送 @导入QQ歌单8162013709 或 @导入网易歌单6787973700。也支持平台分享链接；QQ 数字歌单 ID 和路径链接可直接解析，QQ c6 短链会受限跳转解析。网易云链接只读取 id，忽略 uct2 等分享参数。每个发言者同时只能有一个导入任务；读取完成后会显示歌单名、创建者、总数、新增/重复数及最多三首样例。只有回复 @确认导入 才会在一个数据库事务中去重写入收藏，@取消导入 放弃；预览五分钟后失效。单次上限 3000 首，平台元数据不完整或曲目详情缺失时整批拒绝，不会部分收藏。

导入请求在播放器后台执行，不会阻塞聊天监听。去重键是平台标识与平台歌曲 ID；同一平台 ID 再次收藏或导入会刷新曲目元数据并保留原收藏时间，不同 ID 即使标题相同也视为不同曲目。平台已保存的登录凭据只由适配器内部使用；凭据不显示在命令或日志中。公开歌单无需登录。私密歌单是否可读由平台与当前已保存的登录态决定；QQ 私密歌单当前不保证支持。歌单内容仅保存稳定曲目标识和元数据，不保存有时效的播放 URL。

## 推荐窗口

发送 @歌单 后进入与点歌确认相同类型的聊天观察独占窗口，总期限为 20 秒，建立观察基线的时间也计入期限。窗口只接受当前大厅的蓝色聊天消息，并核对发送者与当前歌单 owner；好友粉色消息、未知发送者、历史基线和其他用户的选择不会被窗口消费。

首次最多展示五首，回复末尾提示“回复@1-@N选择，@换一批 @关闭。”。@1 到 @5 只在此活动窗口内有效，窗口外不会路由为歌单命令。重抽优先展示尚未出现的歌曲；例如收藏池有八首时，候选按 5 首、剩余 3 首展示。少于五首时展示所有剩余歌曲，不用已展示歌曲填充。剩余歌曲耗尽后，下一次重抽重新开始一轮；重抽不会延长 20 秒窗口。

有效输入先被当前窗口消费；选择或关闭会在播放和最终回复前释放聊天观察独占，重抽在同一个独占窗口内继续等待。观察超时、暂停、停止、配置重载、读取失败或播放失败都会清理当前用户的窗口状态。

窗口外的 @1 到 @5 不会被普通命令路由或自定义工作流认领。成功选择会使用现有命令锁，以防视觉会话重建或 OCR 修订造成重复执行；窗口内的无效编号只消费当前消息，不写入成功锁。

# 海龟汤

海龟汤是默认关闭的大厅娱乐玩法。开启前请准备题库文件，并在 `config.yaml` 的 `turtle_soup.enabled` 中启用。

## 游戏命令

```text
#海龟汤
#状态
#结束
#他认识死者吗？
##1男人是灯塔管理员
##2他关灯后导致船只失事
##提交
##取消
```

- 空闲时发送 `#海龟汤` 随机开局；进行中再次发送会重发汤面。
- `#状态` 查看时长、参与人数和提问数量，`#结束` 主动结束。
- 只有当前大厅中以 `#` 开头的正文才会作为问题。
- `##编号内容` 暂存长答案，不会立即裁决；编号从 `1` 开始且提交时必须连续。
- `##提交` 按编号合并答案后提交一次裁决，缺段时会提示缺少的编号并保留草稿。
- `##取消` 清空当前昵称的暂存内容。

第一位发送有效问题的玩家会自动加入本局。普通问题会得到“是、否、无关、部分正确”等简短回复；完整还原汤底时结束并公布结算。

## 题库

复制 `turtle_soup.example.yaml` 为 `turtle_soup.yaml`，按示例填写：

```yaml
题目:
  - id: example-001
    标题: 示例题目
    汤面: 游戏内发送的背景故事
    汤底: 结算时公布的真相
    裁决备注: 帮助 AI 理解关键事实
    启用: true
```

题目 ID 不能重复，关键字段不能为空。每次选中的题目会记录到 `turtle_soup.used_state_path`，之后不会再次随机选中；需要重新使用时，请在停止程序后手动处理使用记录。

## AI 配置

海龟汤使用独立的 `turtle_soup.ai` 配置，不会复用点歌 AI：

```yaml
turtle_soup:
  enabled: true
  question_bank_path: turtle_soup.yaml
  ai:
    endpoint: https://api.openai.com/v1/chat/completions
    api_key: ""
    model: gpt-5.6
    max_tokens: 1024
    http_proxy: ""
```

`api_key`、`endpoint` 和 `model` 必须填写。网络请求超时或裁决失败时会按 `retry_count` 重试；AI 不可用不会泄露汤底，也不会自动结束对局。

## Web 控制

Web 面板可以开始指定题目、查看状态和结束对局，但不会显示进行中的汤底。题库管理接口只接收已经整理好的题目内容，建议在提交前自行检查题面和汤底。

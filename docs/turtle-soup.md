# 海龟汤

海龟汤是默认关闭的大厅娱乐玩法。开启前请准备题库文件，并在配置中心把 `turtle_soup.enabled` 设为 `true`。

## 游戏命令

```text
#海龟汤
#状态
#结束
#他认识死者吗？
##1男人是灯塔管理员
##2他关灯后导致船只失事
##提交
##取消
```

- 空闲时发送 `#海龟汤` 随机开局；进行中再次发送会重发汤面。
- `#状态` 查看时长、参与人数和提问数量，`#结束` 主动结束。
- 只有当前大厅中以 `#` 开头的正文才会作为问题。
- `##编号内容` 暂存长答案，不会立即裁决；编号从 `1` 开始且提交时必须连续。
- `##提交` 按编号合并答案后提交一次裁决，缺段时会提示缺少的编号并保留草稿。
- `##取消` 清空当前昵称的暂存内容。

第一位发送有效问题的玩家会自动加入本局。普通问题会得到“是、否、无关、部分正确”等简短回复；完整还原汤底时结束并公布结算。

## 题库

题库是内容数据文件。复制发布包中的 `deps/docs/turtle_soup.example.yaml` 为 `deps/turtle_soup.yaml`，按示例填写：

```yaml
题目:
  - id: example-001
    标题: 示例题目
    汤面: 游戏内发送的背景故事
    汤底: 结算时公布的真相
    裁决备注: 帮助 AI 理解关键事实
    启用: true
```

题目 ID 不能重复，关键字段不能为空。每次选中的题目会记录到配置中心 `turtle_soup.used_state_path` 指定的文件，之后不会再次随机选中；需要重新使用时，请在停止程序后手动处理使用记录。

## AI 配置

在配置中心 `turtle_soup` 段填写 AI 服务地址、密钥和模型；需要通过代理连接时，同时填写代理地址。海龟汤使用独立的 AI 配置，不会复用点歌 AI。

AI 连接信息填写完整后保存。请求超时或裁决失败时，程序会按配置的次数重试；AI 暂时不可用时，对局保持当前进度，汤底继续隐藏。

系统提示词和裁决提示词可在配置中心调整，留空时使用内置内容。可根据房间需要补充规则，程序会结合当前题目和提问进行判断。

## Web 控制

Web 面板可以开始指定题目、查看状态和结束对局。进行中的汤底保持隐藏；添加题目前，先检查题面和汤底是否完整。

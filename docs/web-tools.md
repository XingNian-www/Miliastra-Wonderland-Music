# Web 面板使用

## 1. 打开面板

浏览器打开 `http://127.0.0.1:18888/`，在页面「访问令牌」中填写 `config.yaml` 的 `http.access_token`。本机和远程访问都需要令牌；首次启动时若该字段为空，程序会自动生成并写回。

高级工具页地址为 `http://127.0.0.1:18888/tools`。

## 2. 主面板

主面板可以查看游戏窗口、聊天监听模式、当前歌曲、点歌队列、最近日志、识别到的聊天和待处理任务，也能查看海龟汤、谁是卧底及自定义流程状态。

点击播放、点歌、切歌、音量、队列、歌词、启动游戏或监听模式按钮后，操作会按顺序执行。提交后到任务列表查看进度和结果；失败时先阅读原因，再决定是否重试。

## 3. 配置中心

在「配置中心」找到需要调整的配置段，修改后先预检，再保存。校验失败时按对应字段的提示修正。页面会说明配置是立即生效、在任务结束后自动重载、在播放结束或暂停后自动重载，还是需要重启。

存储位置、Web 监听和日志等启动配置在 `config.yaml` 中修改，并在修改后重启整个程序。保存功能配置后可查看历史版本，需要时回滚。聊天监听模式会记住上次通过命令选择的模式，重载或重启后继续使用。

密钥在页面上显示为掩码。留空或保持掩码会保留已保存的值；需要删除时使用该字段的「清除」按钮。访问令牌必须保持非空。

身份映射中，「游戏内昵称」用于识别好友和判断权限，「显示昵称」用于游戏回复和面板展示；显示昵称留空时使用游戏内昵称。管理员和主人身份也在这里配置，修改显示昵称不会改变权限。

AI 点歌在 `ai` 段设置服务地址、密钥、模型和代理，歌曲审核在 `song_review` 段设置开关和阈值。提示词留空时使用内置默认值。

## 4. 常用远程操作

| 功能 | 操作 |
| --- | --- |
| 点歌 | 输入关键词搜索，选择歌曲播放或加入队列 |
| 播放控制 | 使用暂停、继续、上一首、下一首按钮，拖动音量滑块或输入音量 |
| 队列管理 | 查看待播歌曲，按需删除或清空队列 |
| 聊天控制 | 发送大厅消息，切换一级或二级监听 |
| 游戏任务 | 选择启动游戏、进入千星或检测大厅，并查看任务结果 |
| 玩法控制 | 开始或结束海龟汤、谁是卧底 |

聊天中的 AI 点歌、管理员拉黑、邀请和塔罗命令见[用户使用指南](user-guide.md)。

## 5. 歌曲信息中的点歌人

当前歌曲和待播队列会显示点歌人。聊天点歌记录发起人的聊天昵称；配置了显示昵称后，面板按该名称展示。没有另行指定点歌人的 Web 点歌显示为 `WEB/API`。

## 6. 点歌榜

在播放页找到「点歌榜」，选择最近 7 天、最近 24 小时、最近 30 天或全部；默认显示最近 7 天。点击「刷新」可重新读取。最近几天从查看时刻向前计算，例如最近 7 天指过去 7 × 24 小时。

榜单按成功播放的新点歌次数排名，同一首歌再次点播并成功播放也会计数。次数相同时，最近成功播放的点歌排在前面。页面的“前 N 名 / 已显示人数”表示当前显示的范围和人数。

以下情况不增加次数：搜索或播放失败、重复点歌被拦截、歌曲在播放前被删除、排队后一直未播放，以及重启恢复、暂停后继续、上一首回放。没有点歌人的自动播放也不计入。

人工点歌成功播放同样计数，没有另行指定点歌人时记到 `WEB/API`。记录按点歌时的原始名称分别统计，再使用当前配置的显示昵称展示；不同原始名称即使显示昵称相同，也会分开排列。游戏内改名后，旧名称的记录保持独立。

榜单从已有的点歌记录计算。升级前没有记录的点歌不会补入，旧版本留下的错误次数也不会自动修正。

读取失败或超过 15 秒未完成时，页面会显示失败或超时提示，可点击「刷新」重试。切换时间范围后，榜单按新选择显示。

## 7. 高级工具页

打开 `/tools`，根据要检查的内容选择工具：

| 需要检查的内容 | 操作 |
| --- | --- |
| 游戏画面 | 查看最新截图，确认游戏窗口可用 |
| 文字识别 | 设置识别区域，运行 OCR 或扫描聊天 |
| 界面与大厅 | 查看当前界面状态和大厅名称 |
| 模板匹配 | 选择配置中已有的模板名称并查看匹配结果；祈愿入口可选“祈愿” |
| 按键与点击 | 填写按键或坐标后执行 |
| OCR 与 AI 点歌 | 检查 OCR 后端和 AI 点歌候选 |

操作前确认游戏窗口已打开且可以操作。正式聊天命令到来时会优先执行，工具失败会显示在结果中。模板匹配只使用已配置的模板名称。

## 8. 任务结果

提交操作后，在任务列表查看状态：

| 页面状态 | 含义 |
| --- | --- |
| `queued` | 等待执行 |
| `running` | 正在执行 |
| `completed` | 执行成功 |
| `failed` | 执行失败，打开结果查看原因 |
| `canceled` | 尚未执行就被取消 |

页面长时间没有更新时，先确认程序仍在运行、游戏窗口没有关闭，再刷新主面板。页面能打开但读取或操作失败时，检查页面填写的令牌是否与 `config.yaml` 中的 `http.access_token` 一致。

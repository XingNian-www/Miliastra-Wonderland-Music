# Web 面板使用

## 打开面板

默认地址为：

```text
http://127.0.0.1:18888/
```

高级工具页为 `/tools`。本机和远程访问都需要在页面「访问令牌」中填写 `config.yaml` 的 `http.access_token`；首次启动时若该字段为空，程序会自动生成并写回。

## 主面板

主面板可以查看：

- 游戏窗口和当前聊天监听模式。
- 播放器状态、当前歌曲和点歌队列。
- 最近日志、OCR 结果和待处理任务。
- 海龟汤、谁是卧底和自定义流程的公开状态。

面板中的播放、点歌、切歌、音量、队列、歌词、启动游戏和监听模式按钮会按顺序执行。页面返回任务编号后，可以在任务列表中查看执行结果。

## 配置中心

配置中心页面用于查看和修改全部功能配置。功能配置保存在数据库 `deps/data/playback.sqlite3` 中；数据库路径、Web 监听和日志等启动配置在 `config.yaml` 中修改。

- 按段展示字段、默认值与生效级别（立即生效 / 任务结束后自动重载 / 播放结束或暂停后自动重载 / 重启生效）。
- 修改后先预检再保存；校验失败会逐字段提示。
- 需要重载的配置会在当前任务结束后自动处理；页面会显示立即生效、自动重载或需要重启。
- `config.yaml` 中的启动引导配置仍需人工重启整个程序后生效。
- 保存生成新的配置版本，可查看历史版本并回滚。
- 聊天监听模式会单独持久化；重载或重启后按上次通过命令选择的模式恢复，不以重启瞬间所在的界面覆盖用户选择。
- secret 字段（API 密钥等）在页面上只显示掩码，提交时留空或保持掩码不会覆盖已保存的值；清除密钥需使用该字段的「清除」按钮。`http.access_token` 必须保持非空。

身份映射中的「游戏内昵称」对应 `nickname`，「显示昵称」对应 `note`。非空显示昵称用于游戏回复、Web 面板和 HTTP API；留空或没有映射时显示游戏内昵称。好友定位和权限判断使用游戏内昵称，配置编辑接口保留原始映射字段。

## 常用远程操作

面板按钮对应的常用功能：

| 功能 | 说明 |
| --- | --- |
| 点歌 | 搜索并播放，或把歌曲加入队列 |
| 播放控制 | 暂停、继续、上一首、下一首和音量 |
| 队列管理 | 查看、删除和清空队列 |
| 聊天控制 | 发送大厅消息、切换一级/二级监听 |
| 游戏任务 | 启动游戏、进入千星、检测大厅 |
| 玩法控制 | 开始或结束海龟汤、谁是卧底 |

直接调用 API 时，通过请求头 `X-Miliastra-Token` 提交 `http.access_token`。

## 歌曲信息中的点歌人

歌曲信息会包含统一的 `requester` 字段：

- `/status`：当前播放歌曲的点歌人。
- `/queue`：每个待播歌曲的点歌人。
- `/monitor`：当前歌曲和待播队列会包含点歌人。
- `/state`：`playback.activeRequest.requester` 包含当前活动歌曲的点歌人。

聊天点歌会记录发起点歌的聊天用户名。直接调用 `/queue/add` 或
`/player/play-track` 时，可以通过 `requester` 参数指定点歌人；未指定时使用
`WEB/API`。播放请求必须提交结构化 `trackRef` 和 `metadata`。

## 高级工具页

高级页用于人工确认当前画面和配置：

- 查看最新游戏截图。
- 通过 API 主动执行大厅检测并取得截图（`/hall-screenshot`；人数超过 7 时返回滚动前后合并图）。
- 在指定区域运行 OCR 或扫描聊天。
- 查看当前 UI 状态和大厅名称。
- 匹配配置中已有的模板。
- 发送按键或点击坐标。
- 检查 OCR 后端和 AI 点歌候选。

工具操作需要游戏窗口处于可用状态。工具不会替代正式聊天命令；正式命令到来时会优先执行。不要在模板测试中填写任意本地文件路径，只使用配置中已有的模板名称。

## 任务结果

提交操作后页面会显示任务状态：

- `queued`：等待执行。
- `running`：正在执行。
- `completed`：执行成功。
- `failed`：执行失败，可在结果中查看原因。
- `canceled`：尚未执行就被取消。

如果页面长时间没有更新，请先确认程序仍在运行、游戏窗口没有关闭，并刷新主面板。

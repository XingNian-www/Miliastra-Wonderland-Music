# 用户使用指南

## 1. 首次运行

运行前请确认：

- 使用 Windows，并让游戏画面分辨率与 `config.yaml` 中的坐标配置相符。
- 游戏已经安装，且 `window.target_process` 填写了正确的进程名。
- FeelUOwn 已启动并开启 TCP RPC，默认地址为 `127.0.0.1:23333`。
- 发布包中的 `assets/`、`models/` 和 `config.yaml` 位于程序可读取的位置。
- 程序以管理员权限运行，这样才能操作游戏窗口和发送按键。

启动程序后，默认会进入常驻监听。首次使用建议先打开 Web 面板确认游戏窗口、OCR 和播放器状态。

## 2. 启动游戏与进入千星

如果启用了 `startup`，程序可以在启动时或通过 Web 面板执行以下任务：

- **启动游戏**：查找已运行的官服/国际服窗口；找不到时按 `startup.exe_path` 尝试启动，进入游戏主界面后结束。
- **进入千星**：从游戏主界面按 `M` 打开地图，匹配右下角星型入口并点击；地图侧栏打开后，在右侧选项区域 OCR 查找包含“千星奇域”或“大厅”的选项并点击，随后匹配并点击“确认”，完成后停留在可继续操作的界面。

也可以只启动游戏，再手动执行进入千星。游戏窗口已经处于目标界面时，重复提交对应任务不会重新执行已经完成的步骤。

## 3. 聊天命令格式

大厅命令来自蓝色聊天消息，好友私聊命令来自粉色聊天消息：

```text
用户: @点歌 晴天 周杰伦
[好友名]: @麦克风
```

命令名与参数之间使用空格分隔。黄色标识只用于辅助识别聊天，不是命令来源。`@帮助` 显示点歌帮助，`#娱乐` 或 `@娱乐帮助` 显示娱乐玩法帮助。

## 4. 点歌和播放

| 命令 | 作用 |
| --- | --- |
| `@点歌 歌名 歌手`、`@搜索 歌名 歌手` | 使用默认音乐源搜索并播放 |
| `@AI点歌 歌名 歌手`、`@AI搜索 歌名 歌手` | 搜索候选后由 AI 选择 |
| `@QQ点歌 ...`、`@QQ搜索 ...` | 强制使用 QQ 音乐 |
| `@网易点歌 ...`、`@网易云点歌 ...`、`@网易搜索 ...` | 强制使用网易云音乐 |
| `@B站点歌 关键词`、`@B站搜索 关键词` | 仅好友私聊使用 B 站来源 |
| `@暂停` | 暂停当前播放 |
| `@继续`、`@恢复`、`@播放` | 继续播放 |
| `@下一首`、`@下一曲` | 播放下一首 |
| `@上一首`、`@上一曲` | 播放上一首 |
| `@音量 30` | 设置 0 到 100 的音量 |
| `@状态` | 查询播放器状态 |
| `@大厅检测` | 读取当前大厅名称 |
| `@大厅时间` | 查询已记录的大厅剩余时间 |

如果搜索结果不唯一，机器人会提示 `@确认`、`@跳过`、`@换源` 和 `@AI`。在等待期间没有选择时，会按默认确认处理。AI 命令需要在 `ai` 中填写 API Key；未配置时会直接提示 AI 未启用。

### AI 点歌和歌曲审核

AI 点歌会先搜索歌曲候选，再从候选中选择，不会凭空生成播放地址。可选的 `song_review` 会在游戏内点歌播放前检查歌曲是否符合房间设置；审核等级越高表示歌曲越吵闹或越容易打扰，超过 `max_allowed_level` 的候选会被拒绝。控制台人工播放和队列操作不受歌曲审核限制。

## 5. 队列和歌词

| 命令 | 作用 |
| --- | --- |
| `@队列`、`@列表` | 分批发送完整点歌队列，不压缩歌曲信息 |
| `@队列删除 1` | 删除第 1 首队列歌曲，也可以写多个编号 |
| `@队列清空` | 清空待播放队列 |
| `@歌词` | 查询当前歌词 |
| `@歌词 秒数`（例如 `@歌词 10`） | 在指定秒数内自动发送变化的歌词，最长 30 秒 |
| `@持续歌词` | 主线持续发送歌词；正式命令到来时结束 |
| `@后台歌词` | 后台监听歌词，正式命令执行时暂缓发送，完成后继续 |
| `@停止歌词` | 停止后台歌词 |

队列和播放状态会保存到 `data/`。程序会尽量避免短时间内重复播放同一首歌；需要人工指定播放内容时可使用 Web 面板。

## 6. 聊天监听模式

默认使用一级监听。好友私聊发送以下命令可以切换：

```text
@监听模式 一级
@监听模式 二级
@监听模式 状态
```

一级监听直接观察游戏聊天框。二级监听观察当前大厅气泡和好友未读消息，适合需要持续停留在千星二级界面的场景。切换失败时程序会尝试恢复到可用的监听界面；普通命令会在当前监听模式下继续处理。

## 7. 好友操作和管理

好友私聊支持：

| 命令 | 作用 |
| --- | --- |
| `@邀请1`、`@邀请654321` | 邀请好友进入大厅；数字可作为序号或大厅密码 |
| `@麦克风` | 切换麦克风 |
| `@W/@S/@A/@D [秒数]` | 移动角色，默认 1 秒 |
| `@C` | 按一次 Ctrl |
| `@CW/@CS/@CA/@CD [秒数]` | 组合 Ctrl、中键和方向键 |
| `@F`、`@X` | 在一级界面发送一次对应按键 |
| `@通告 内容` | 向当前大厅发送内容 |
| `@拉黑UID123456789` | 发起 UID 拉黑投票 |
| `@屏蔽UID123456789` | 发起 UID 屏蔽聊天投票 |

邀请确认在大厅发送 `@邀请确认`、`@同意邀请`、`@邀请拒绝` 或 `@拒绝邀请`。投票类操作需要满足配置的同意人数和等待时间。

以下命令用于管理识别状态，不会显示在普通帮助中：

```text
@启用
@禁用
@闲置退出
@闲置退出 20
```

`@闲置退出` 的时间单位为分钟，最小为 15 分钟；触发后会暂停播放器并关闭目标游戏窗口，程序本身继续运行。

## 8. 娱乐玩法

- 成语接龙：发送 `#接龙 成语` 或 `#同音接龙 成语` 开始，详细规则见[成语接龙](idiom-chain.md)。
- 斗地主：发送 `#斗地主` 创建三人房间，详细规则见[斗地主与跑得快](card-games.md)。
- 跑得快：发送 `#跑得快` 创建三人房间，详细规则见[斗地主与跑得快](card-games.md)。
- 海龟汤：发送 `#海龟汤` 开始，详细规则见[海龟汤](turtle-soup.md)。
- 谁是卧底：发送 `#卧底` 或 `#卧底双` 创建报名房间，详细规则见[谁是卧底](undercover.md)。

斗地主和跑得快由 `landlord.enabled` 控制，默认开启；其他玩法按各自配置段控制。首次使用海龟汤或谁是卧底前，还需要准备对应示例文件要求的题库或词库。

## 9. 配置中常用项目

通常只需要修改以下配置：

| 配置段 | 用途 |
| --- | --- |
| `window` | 游戏进程名和画面尺寸 |
| `feeluown` | FeelUOwn 的地址和端口 |
| `http` | Web 面板监听地址、端口和访问令牌 |
| `ocr.backend_priority` | OCR 后端顺序；默认 CPU 即可 |
| `ai` | AI 点歌的地址、密钥、模型和代理 |
| `song_review` | 歌曲审核开关和审核阈值 |
| `idiom_chain` | 成语接龙开关和超时 |
| `landlord` | 斗地主/跑得快开关、组局和出牌超时、托管阈值 |
| `turtle_soup` | 海龟汤开关、题库和 AI 参数 |
| `undercover` | 谁是卧底开关、词库和人数限制 |
| `custom_workflows` | 自定义命令流程 |

远程访问 Web 面板时，把 `http.host` 改为需要的监听地址，并设置非空 `http.access_token`。本机访问建议保持默认的 `127.0.0.1`。

## 10. 自定义命令

在 `custom_workflows` 中可以为大厅或好友添加配置驱动命令。最小示例：

```yaml
custom_workflows:
  enabled: true
  workflows:
    - name: 测试流程
      commands: [测试流程]
      message_types: [pink]
      steps:
        - type: key
          key: F
```

聊天中发送 `@测试流程` 即可触发。内置命令和确认/投票命令优先于自定义命令；每个流程按步骤执行，失败时会停止后续步骤。模板、坐标、按键和发送消息的完整字段以当前 `config.yaml` 为准。

## 11. Web 面板

打开 `http://127.0.0.1:18888/` 可以查看：

- 游戏窗口、监听模式、播放器和队列状态。
- 日志、最近识别到的聊天和待处理任务。
- 远程点歌、播放控制、队列管理、歌词和启动游戏。
- 海龟汤、谁是卧底和自定义流程的可用控制。

`/tools` 高级页可以手动查看截图、测试 OCR、匹配已配置模板和发送按键。工具失败只显示在工具结果中，不会替代或取消正式聊天命令。

调用 `GET /hall-screenshot?quality=88` 会主动进入大厅检测界面并截图：人数不超过 7 时返回一张 JPEG，人数超过 7 时滚动成员列表并将前后两张截图纵向合并后返回；检测失败或游戏窗口不可用时返回 `503`。

## 12. 快捷键与常见问题

- `F7`：暂停或恢复聊天扫描。
- `F12`：退出程序。

### 常见问题

**没有识别到命令**

检查游戏是否处于一级或二级监听对应的界面、聊天标识颜色是否正确，以及 `screen` 坐标是否与当前画面分辨率一致。

**无法播放歌曲**

检查 FeelUOwn 是否运行、TCP RPC 地址是否正确，并先用 `@状态` 或 Web 面板确认播放器连接。

**AI 命令提示未启用**

检查对应配置段的 `api_key`、`endpoint` 和 `model`，保存配置后重新启动程序。

**Web 页面无法访问**

确认程序已启动、端口没有被占用；非本机监听时还需要填写 `http.access_token`。

**游戏关闭后仍显示旧截图**

重新启动游戏窗口并等待下一次有效扫描；目标窗口关闭后，旧画面不会继续作为新的识别结果使用。

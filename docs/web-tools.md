# Web 面板使用

## 打开面板

默认地址为：

```text
http://127.0.0.1:18888/
```

高级工具页为 `/tools`。如果把 `http.host` 改为非本机地址，必须同时填写非空的 `http.access_token`。

## 主面板

主面板可以查看：

- 游戏窗口和当前聊天监听模式。
- 播放器状态、当前歌曲和点歌队列。
- 最近日志、OCR 结果和待处理任务。
- 海龟汤、谁是卧底和自定义流程的公开状态。

面板中的播放、点歌、切歌、音量、队列、歌词、启动游戏和监听模式按钮会按顺序执行。页面返回任务编号后，可以在任务列表中查看执行结果。

## 常用远程操作

面板按钮对应的常用功能：

| 功能 | 说明 |
| --- | --- |
| 点歌 | 搜索并播放，或把歌曲加入队列 |
| 播放控制 | 暂停、继续、上一首、下一首和音量 |
| 队列管理 | 查看、删除和清空队列 |
| 聊天控制 | 发送大厅消息、切换一级/二级监听 |
| 游戏任务 | 启动游戏、进入千星、检测大厅 |
| 玩法控制 | 开始或结束海龟汤、谁是卧底 |

需要鉴权时，在页面的“访问令牌”输入框填写 `http.access_token`。令牌只保存在当前浏览器会话中。

## 高级工具页

高级页用于人工确认当前画面和配置：

- 查看最新游戏截图。
- 在指定区域运行 OCR 或扫描聊天。
- 查看当前 UI 状态和大厅名称。
- 匹配配置中已有的模板。
- 发送按键或点击坐标。
- 检查 OCR 后端和 AI 点歌候选。

工具操作需要游戏窗口处于可用状态。工具不会替代正式聊天命令；正式命令到来时会优先执行。不要在模板测试中填写任意本地文件路径，只使用配置中已有的模板名称。

## 任务结果

提交操作后页面会显示任务状态：

- `queued`：等待执行。
- `running`：正在执行。
- `completed`：执行成功。
- `failed`：执行失败，可在结果中查看原因。
- `canceled`：尚未执行就被取消。

如果页面长时间没有更新，请先确认程序仍在运行、游戏窗口没有关闭，并刷新主面板。

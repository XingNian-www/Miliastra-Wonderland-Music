# 个人歌单

个人歌单按游戏内昵称归属；好友备注名只用于识别和展示，不会把不同用户合并。歌单命令遵循游戏 OCR 的无空格语法。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| @收藏 | 收藏当前正在播放的歌曲 |
| @取消收藏、@歌单删除 | 取消收藏当前歌曲 |
| @歌单 | 打开当前用户的推荐窗口 |
| @1 到 @5 | 选择推荐窗口中的歌曲 |
| @换一批 | 在当前窗口重抽候选 |
| @关闭 | 关闭推荐窗口 |
| @歌单随机、@随机歌单 | 从已收藏歌曲中随机播放 |
| @歌单清空 | 请求清空歌单；需要再次确认 |
| @歌单帮助 | 查看帮助 |

## 推荐窗口

发送 @歌单 后进入与点歌确认相同类型的聊天观察独占窗口，总期限为 20 秒，建立观察基线的时间也计入期限。窗口只接受当前大厅的蓝色聊天消息，并核对发送者与当前歌单 owner；好友粉色消息、未知发送者、历史基线和其他用户的选择不会被窗口消费。

首次最多展示五首。重抽优先展示尚未出现的歌曲；例如收藏池有八首时，候选按 5 首、剩余 3 首展示。少于五首时展示所有剩余歌曲，不用已展示歌曲填充。剩余歌曲耗尽后，下一次重抽重新开始一轮；重抽不会延长 20 秒窗口。

有效输入先被当前窗口消费；选择或关闭会在播放和最终回复前释放聊天观察独占，重抽在同一个独占窗口内继续等待。观察超时、暂停、停止、配置重载、读取失败或播放失败都会清理当前用户的窗口状态。

窗口外的数字命令仍按普通路由处理。成功选择会使用现有命令锁，以防视觉会话重建或 OCR 修订造成重复执行；无效编号只消费当前消息，不写入成功锁。

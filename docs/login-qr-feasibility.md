# 平台登录

程序通过登录辅助器打开音乐平台的官方登录页面。当前支持 QQ 音乐、网易云音乐、酷狗音乐和哔哩哔哩。

## 使用方式

1. 打开 Web 面板的「账号登录」页面。
2. 在需要的平台卡片中点击「登录」。
3. 扫描面板显示的二维码，或在弹出的官方页面完成登录。
4. 返回 Web 面板，确认平台状态显示为「已登录」。

登录二维码只在当前登录会话中有效。二维码过期、加载失败或登录窗口关闭后，请重新点击「登录」。

## 登录结果

- 登录完成后，账号凭据保存在配置的凭据目录中，供播放器使用。
- Web 面板只显示登录状态和账号摘要，不显示完整凭据。
- 登录失败不会覆盖已有的有效凭据。
- 播放时如果平台提示登录失效，请在此页面重新登录；重新登录后，后续点歌会使用新的凭据。

## 环境要求

- Windows 系统已安装 WebView2 Evergreen Runtime。
- 登录辅助器路径和凭据目录使用配置中心「播放」段中的当前值。
- 登录期间保持程序运行，不要手动关闭登录窗口。

登录状态在「账号登录」页面查看；游戏内 `@状态` 查询的是播放器状态。

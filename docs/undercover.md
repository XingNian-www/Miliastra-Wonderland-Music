# 谁是卧底

谁是卧底是默认关闭的多人玩法。开启前请准备词库，并在配置中心把 `undercover.enabled` 改为 `true`。

## 开始游戏

大厅命令：

```text
#卧底
#卧底双
#状态
#开局
#结束
#退出
```

- `#卧底` 创建单卧底报名房间。
- `#卧底双` 创建双卧底报名房间。
- 好友通过私聊 `#加入` 报名，`#退出` 取消报名。
- 人数达到要求后，创建者发送 `#开局`；也可以使用 Web 面板开始。

## 进行中

- 机器人会把位置和词语分别发给好友私聊。
- 每位存活玩家在公屏发送 `#内容` 描述自己的词语，不能直接说出完整词语。
- 全部描述完成后，好友私聊发送 `#A`、`#投A` 等编号投票，也可以发送 `#弃权`。
- `#状态` 查看阶段和发言进度，`#谜底` 只允许对局外好友私聊查询。

描述和投票提交后不能修改。投票平局时会进行一次额外描述和投票；再次平局则无人出局并进入下一轮。

## 结束和重试

- 所有卧底出局时平民获胜；存活平民人数不多于卧底时卧底获胜。
- 玩家在游戏中退出会按出局处理，创建者可以用 `#结束` 结束整局。
- 好友私聊投递失败时，在大厅发送 `#重试` 继续安全的剩余投递；无法确认结果时请使用 `#结束`。
- 描述、投票或整局长时间没有输入时会自动结束。

## 词库配置

词库是内容数据文件。复制发布包中的 `deps/docs/undercover.example.yaml` 为 `deps/undercover.yaml`。每行填写一对词语，格式为 `平民词:卧底词`；顺序相反的词对视为同一对。

`undercover` 功能段在配置中心修改，字段结构如下（示意）：

```yaml
undercover:
  enabled: true
  word_bank_path: undercover.yaml
  min_players: 4
  double_min_players: 6
  max_players: 11
```

词对在第一次发词前会标记为已用，之后不会再次抽到。人数和阶段时间可以在配置中心中调整。
